# 0.7.6 — единые кнопки закрытия окон

Окна восстановления пароля, добавления группы, редактирования ячейки расписания и мобильное меню используют тот же красный SVG-крестик, что уведомления и тосты. Область нажатия 44×44, доступное название и подсказка сохранены. Крестик находится справа в заголовке; дублирующие текстовые кнопки закрытия/отмены внизу форм убраны. Действие обновления расписания при конфликте остаётся отдельной текстовой кнопкой.

Начальный фокус остаётся в поле формы. Во время сохранения расписания крестик отключается, Escape также не закрывает редактор; при ошибке оба способа снова доступны, введённые значения остаются. Закрытие без сохранения не отправляет изменений.

Проверены восстановление пароля с подставленным email и имитацией отправки, мобильное меню, уведомления, тосты, обе формы расписания, фокус, Escape, отмена изменений, медленный ответ и конфликт сохранения. Выполнена браузерная проверка всех разделов трёх ролей на восьми размерах экрана. Используются изолированные Auth/API-ответы, без создания реальных аккаунтов и отправки писем.

Изменения только клиентские. Версия кэша оболочки обновлена до 0.7.6; миграция БД и развёртывание lms не требуются.
