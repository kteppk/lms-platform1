# Релиз 0.7.1

Главная кабинетов — две независимые ленты: «Новости сайта» (журнал изменений и объявления) и «Новости техникума». Публикации идут по времени публикации от новых к старым, по 20 записей с кнопкой загрузки более ранних. Полный длинный текст раскрывается без перехода на другую страницу. Записи хранятся в `news_posts`; создание, изменение и удаление доступны только администратору, изменение защищено номером revision. Импортированные сообщения и коммиты не редактируются через форму. Прежние явные объявления перенесены в ленту, история уведомлений сохранена.

«Новости и объявления» в кабинете администратора позволяет выбрать ленту, тип публикации, заголовок и текст. По умолчанию новость не создаёт уведомлений. Для важного сообщения администратор явно включает общую рассылку и при необходимости выделение. Изменение или удаление новости не переписывает уже доставленные уведомления.

Журнал коммитов автоматически загружается серверной функцией из публичной ветки main репозитория `kteppk/lms-platform1`, начиная после `264a2e1`. После открытия ленты сервер обновляет историю не чаще раза в пять минут. Между запросами используется общая блокировка/кэш в `news_sync`. Уникальный source_key предотвращает дубли. При ошибке GitHub или лимите запросов сохранённая история остаётся доступна, курсор не продвигается. Сброс/перезапись истории Git не удаляет записи и не импортирует всю старую историю повторно. Новые коммиты не создают массовых уведомлений. Для ручного пояснения релиза можно опубликовать «Журнал обновлений» через редактор.

Отдельный раздел «Книги» и его формы удалены из интерфейса и мобильного меню. Старые записи и файлы не удалены: прежние PDF без привязки к предмету доступны в «Материалах», привязанные — внутри предмета. У преподавателя его файлы доступны по подписанным ссылкам. Для новых PDF, презентаций и видео используется общая форма материала; текст при наличии файла необязателен. Формат `kind=books` оставлен только для совместимости прежних данных и API.

Поиск предметов работает по названию и описанию, без учёта регистра и различия ё/е, учитывает все введённые слова. Длинное описание ограничено только на карточке; градиент появляется при фактическом переполнении. При открытии предмета полное описание выводится у студента и у преподавателя, без ограничения высоты.

«Аккаунты и роли» показывает общее число аккаунтов, студентов, преподавателей, администраторов, регистрации за 7/30 дней и таблицу последних шести месяцев. Все категории считаются по текущей роли, поэтому администраторы не дублируются в числе преподавателей. Месяцы определяются по времени Кызыла. Статистика доступна только администратору.

## Следующие выпуски

Единый источник версии — `release.json`, текущая версия **0.7.1**. Перед следующим релизом измените title/notes и выполните:

```powershell
npm run release -- patch
```

Команда повысит версию до 0.7.2, синхронизирует package.json/package-lock.json, сформирует release.js и обновит индикаторы и версии локальных ресурсов в HTML. Для крупных изменений доступны minor и major. Сгенерированные файлы включаются в тот же релизный коммит. Первая подготовка без повышения: `node scripts/release.cjs`. Не меняйте githubBaseCommit при обычных релизах: это начало истории обновлений. Одна версия соответствует одному выпуску; промежуточные коммиты появляются в журнале отдельно.

Индикатор версии расположен внизу боковой навигации после «Мой профиль» и под списком разделов мобильного меню. Тесты проверяют согласованность версии, права, независимость лент, отсутствие неявных рассылок, пагинацию, кэш импорта, поиск, полные описания и сохранность PDF. Выпуск: миграция, функция lms, коммит и публикация GitHub Pages, живая проверка и удаление только временных проверочных данных.
