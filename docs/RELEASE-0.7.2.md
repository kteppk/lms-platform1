# 0.7.2 — телефоны и слабый интернет

Firebase App/Auth 12.10.0 поставляются с сайтом без изменения SDK. Файлы сверены с официальным gstatic побайтово. Вход больше не ждёт загрузку этих двух файлов с другого домена; обращения к самому Firebase Auth для аутентификации остаются необходимы. Форма поддерживает автозаполнение email/пароля, показ пароля, явное сохранение входа на личном устройстве, сеанс на общем устройстве и восстановление пароля по email. Восстановление проверяется только в локальном Auth Emulator, без отправки писем настоящим пользователям.

Service Worker сохраняет только статические файлы из сгенерированного sw-manifest.js: HTML, JS, CSS и текущий SDK. GET-запросы к API, файлы хранилища, POST, токены, оценки, ответы и личные профили не помещаются в CacheStorage. Область кэша включает путь проекта, поэтому другие сайты того же GitHub Pages origin не затрагиваются. Для первого сохранения оболочки нужен работающий интернет. Установка выполняется после загрузки страницы, с двумя одновременными запросами. Предыдущий выпуск продолжает работать, пока новая оболочка не загрузится полностью. При навигации сеть получает до 2,5 секунды, затем используется имеющийся HTML; запрос может завершиться в фоне.

Новый Service Worker ждёт закрытия прежних вкладок или явного нажатия «Обновить сайт». Он не перезагружает текущую работу автоматически. Установка через кнопку блокируется при открытой незавершённой попытке теста; перед перезагрузкой пользователь получает предупреждение о формах.

`connection.js` хранит ограниченный набор справочных ответов: группы, регулярное и дополнительное расписание, предметы и новости. Ключи разделены по UID. Сохраняются максимум 18 записей, суммарно до 550000 JSON-символов; отдельный ответ — до 160000 символов. Копии старше семи дней не используются. Короткое время повторного использования без запроса: расписание — 30 секунд, группы — пять минут, предметы и новости — минута. Совпадающие одновременные чтения используют один запрос. Остальные действия не получают дискового кэша.

При медленном ответе справочные данные можно показать из кэша через 900 мс, с датой копии и предупреждением о возможных изменениях. Фоновое чтение обновляет сохранённые данные. «Обновить» расписание и «Обновить новости» запрашивают сеть без ожидания срока кэша. Ошибки прав не подменяются успешным ответом кэша. Изменения, тесты и отправка ответов не ставятся в офлайн-очередь. При потере связи показанная ранее копия расписания не предоставляет административных прав редактирования.

После перезагрузки без сети кабинет сначала пытается проверить профиль на сервере. Если это невозможно, доступна отдельная страница offline.html с ранее просмотренным расписанием. Она не открывает сохранённые роли, оценки или персональный кабинет. Последние замены и дополнительные датированные занятия нужно проверять в подключённом кабинете. Сообщение на копии явно указывает, что актуальность не подтверждена.

Сохранение входа использует стандартную персистентность Firebase Auth; пароль приложение самостоятельно не записывает. На общем устройстве справочные копии и черновики находятся в sessionStorage. На личном — в localStorage. При смене аккаунта и выходе соответствующие копии очищаются, запоздалый ответ не восстанавливает кэш вышедшего пользователя. Выход при наличии несохранённого черновика требует подтверждения, чтобы не удалить его незаметно.

Черновики тестов сохраняются по прежнему принципу версии попытки. Потеря связи не останавливает серверный срок и не создаёт оценки. После подключения восстанавливается та же попытка; сервер решает, можно ли ещё принять ответы. Повторное создание работы при неизвестном результате запроса не выполняется. Запросы имеют ограничение времени, оборванный JSON не считается успешным ответом. Уведомления загружаются в фоне без задержки первого экрана; частота фонового опроса — две минуты, при экономии трафика/2G — пять минут. В скрытой вкладке и без подключения опрос пропускается. Модуль полей ФИО загружается при необходимости.

Проверки: модульные тесты кэша, разделения аккаунтов, выхода, дедупликации, ошибок и манифеста; реальный браузер с потерей связи и перезагрузкой, продолжением одной попытки, однократной серверной оценкой, чтением расписания, сеансом общего устройства и проверкой CacheStorage; ограничение 3G (800 мс, 40 КБ/с загрузка); все три кабинета на восьми размерах; прежние новости, предметы, PDF, ручная проверка, результаты и экспорт. scripts/release.cjs генерирует версии ресурсов, sw.js и sw-manifest.js для каждого выпуска. Для текущего изменения миграция БД не требуется.
