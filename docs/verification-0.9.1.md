# Проверка версии 0.9.1

Завершена 18.11.2026, 12:59 по времени Кызыла. Рабочий адрес: https://kteppk.github.io/lms-platform1/.

На опубликованном сайте через временные аккаунты проверены:

- Кабинеты студента, преподавателя, куратора и администратора; гостевая и облегчённая страницы.
- Сохранение специальности, курса, группы, даты поступления и рождения. Другому пользователю API возвращает возраст, но не полную дату рождения.
- Прямое открытие учебных сведений студента и профессиональных сведений преподавателя в «Людях».
- Публикация новости куратором из общей ленты без отдельного раздела управления. Проверочная публикация затем удалена.
- Закреплённая панель и доступность «Мой профиль» при высоте окна ПК 580 пикселей.
- Настоящее скачивание Excel для выбранной группы. Общая книга сформирована из опубликованной базы: 22 листа, все XML-части файла успешно разобраны.
- Отключённая кнопка включения напоминания до подтверждения предупреждения.
- Настоящее напоминание: отдельная тестовая группа, явная подписка, пара с будущим временем начала. Ежеминутная задача сама создала напоминание за пять минут, обработчик ответил HTTP 200, уведомление появилось в обычном профиле Chrome.
- Прежние материалы, списки тестов, лайки после перезагрузки, закрытый чат и немедленный отказ API после отзыва роли.

Автоматические проверки дополнительно покрывают версии записей, права на собственные новости, приоритет времени ячейки, отсутствие формул из пользовательского текста в Excel, дедупликацию напоминаний, отмену пары, истечение срока и отписку. Интерфейс пяти режимов проверен при ширине 320/390 пикселей. Физические устройства Android и iOS не использовались.

Итоговый аудит: **22 группы, 692 существующие ячейки, 8 материалов**. Временных групп, профилей, сообщений и новостей нет. Проверочные Firebase-аккаунты, устройства и подписки удалены. Планировщик напоминаний включён; пользовательские напоминания автоматически никому не подключались.
