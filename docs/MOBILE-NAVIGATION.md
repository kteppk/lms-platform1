Мобильная навигация

На экранах до 900 px кабинет использует нижнюю панель из пяти кнопок. Для студента основные разделы — главная, предметы, расписание и результаты; для преподавателя результаты заменены журналом, для администратора доступны аккаунты и уведомления. Кнопка «Ещё» открывает все разделы, профиль и выход из аккаунта в диалоге с крупными кнопками. В обычном браузере сохраняется боковое меню.

`mobile-nav.js` использует существующие кнопки кабинета и ту же функцию переключения разделов. Состояние навигации синхронизируется с исходным меню, в том числе при восстановлении попытки и переходах из уведомлений. Дополнительные ссылки не загружают страницу заново и не создают другую попытку теста. Диалог закрывается кнопкой, Escape, выбором раздела, нажатием на фон или переходом к широкой версии. Поддерживаются фокус, aria-current и aria-expanded.

`mobile-nav.css` задаёт компактную шапку, зоны нажатия от 44 px, поля с шрифтом 16 px, отступы безопасной области экрана и места под нижнюю панель. Уведомления расположены над навигацией, на узком экране одновременно показывается последнее всплывающее сообщение. Аккаунты администратора представлены карточками. Длинное ФИО не расширяет шапку или страницу.

Для повторной проверки нужны Node.js и установленный Google Chrome:

```sh
npm ci
npm run test:mobile
npm run test:mobile -- --published
```

Проверка открывает настоящие HTML/JS/CSS в Chrome с сенсорным режимом. Firebase Auth и ответы API подменяются внутри проверочного браузера: рабочие аккаунты, роли, тесты и материалы не создаются и не изменяются. Флаг `--published` использует файлы GitHub Pages с теми же изолированными данными. Проверяются ширины 320, 360, 390, 430, 768 и 844 px, горизонтальное положение, все разделы трёх кабинетов, размеры кнопок, отсутствие боковой прокрутки, диалог и фокус, сохранение ответов и срока попытки при переходах и возврат к меню на экране 1440 px. Дополнительно задерживается загрузка `portal.js`, чтобы проверить запуск на медленном соединении. Это браузерная проверка размеров экрана, не проверка на физических телефонах.
