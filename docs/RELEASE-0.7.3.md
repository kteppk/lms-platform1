# 0.7.3 — расписание и единая лента

Убраны метка «Каждую неделю» и навигационные ссылки на дни в расписании. Сами таблицы дней, повторяющееся расписание, дополнительные датированные занятия и редактор администратора сохранены.

В блоке уведомлений оставлен один колокольчик размером 46×46. Неподписанное состояние — обычный контур и подсказка «Подписаться на расписание». После подтверждённой сервером подписки показывается тост, колокольчик становится красным и перечёркнутым. Его повторное нажатие отписывает от выбранной группы. Кнопка имеет название для скринридера, aria-pressed и подсказку о текущем действии; цвет не является единственным обозначением состояния.

Справка под кнопкой объясняет подписку и отписку, получение будущих изменений в разделе «Уведомления», обновление администратором, ручную проверку актуальности и сохранённые копии при слабом интернете. В центре подписок также остались только группы. Выбор группы для просмотра не включает подписку автоматически.

Новые подписки на отдельные предметы и «мои занятия» закрыты в API и RPC. Прежние записи этих видов сохранены в БД, скрыты из интерфейса и больше не участвуют в доставке событий. Они не преобразуются в подписку на всю группу, чтобы не расширять прежнюю аудиторию без согласия. Все действующие подписки на группы и ранее доставленные уведомления сохраняются. Смена предмета/аудитории/преподавателя/времени и отмена пары доставляются только подписчикам соответствующей группы. Личные результаты и явные объявления администрации продолжают работать.

На главной — одна общая лента с тегами «Новости сайта» и «Новости техникума». Сервер возвращает обе категории единым запросом `listNews {channel:"all"}`, в общем порядке published_at DESC, id, по 20 записей. Кнопка загрузки ранних записей продолжает этот порядок. Повторы ID при сдвиге страниц новыми публикациями не отображаются. Автоматический импорт коммитов вызывается и для объединённой ленты. Полный текст, тип публикации и ссылка на коммит сохранены.

Редактор администратора выбирает тег публикации; список по умолчанию показывает все новости в одной ленте, с возможностью фильтра категории. Публикации не удаляются и не теряют даты. Существующие вызовы listNews с site/college поддерживаются для совместимости. Права публикации и ручная рассылка уведомлений не меняются.

Миграция 20261114000100 обновляет функции подписок и news_feed без изменения материалов, тестов и расписания. Порядок выпуска: миграция, функция lms, GitHub Pages. Версия 0.7.3 создаёт новый набор кэша оболочки; прежняя открытая вкладка не перезагружается автоматически. Режим слабого интернета и сохранённые черновики остаются.

Проверки: недоступность новых subject/mine подписок, отсутствие доставки по старым записям, идемпотентность group, изоляция групп и владельцев, отписка, единая пагинация с тегами, реальные нажатия колокольчика, цвет/перечёркивание/тост, справка, отсутствие старых элементов и сохранность офлайн-режима и учебных сценариев. Сквозные проверки создают только временные собственные аккаунты/группы и не рассылают общие проверочные уведомления.
