# Проверка опубликованной версии 0.9.0

Завершена 18 ноября 2026 года, 10:29 по времени Кызыла (UTC+7).
Рабочий адрес: https://kteppk.github.io/lms-platform1/.

Проверены в настоящей базе через отдельные временные аккаунты:

- Регистрация и вход в кабинеты студента, преподавателя, администратора и куратора.
- Публичные новости, фильтр тегов, порядок публикаций, расписание выбранной группы и облегчённая страница.
- Лайк и снятие лайка с сохранением после перезагрузки.
- Доступ к материалам и API списков тестов в обоих учебных кабинетах.
- Мобильное расписание и восстановление выбранной группы после перезагрузки.
- Отсутствие чата у студентов и преподавателей, отказ при прямом запросе к API.
- Отправка сообщения куратором, получение администратором, история после перезагрузки и немедленный запрет API после отзыва роли.
- Настройки браузерных уведомлений, защита обработчика доставки отдельным секретом.
- Настоящая push-подписка в отдельном обычном профиле Chrome: планировщик вызвал обработчик, сервис принял отправку, уведомление появилось в браузере. Изолированный режим инкогнито для этой проверки не подходит.

Автоматические проверки: 57 успешных тестов базы и логики приложения; интерфейс пяти режимов проверен на компьютере и ширине 320/390 пикселей. Физические устройства Android и iOS не использовались.

Временные Firebase-аккаунты, профили, сообщения чата, лайки, подписки, устройства и тестовые уведомления удалены. Контрольные суммы существующих групп, ячеек расписания, материалов и тестов совпали до и после проверки. Итоговый аудит: 22 группы, 692 ячейки расписания, 8 материалов; тестовых аккаунтов и сообщений нет. На момент проверки в действующей базе не было созданных тестов; сохранение попыток, история и ручная проверка покрыты автоматическими тестами.

Первому куратору назначена роль `curator`. Планировщик `lms-web-push` активен; проверяет очередь каждую минуту и вызывает функцию только при наличии готовых отправок.

Для включения push: **Уведомления → Уведомления на этом устройстве → Включить уведомления**. Изменения расписания приходят только по группам с активной подпиской через колокольчик. Объявления администрации включаются отдельной отметкой.

Повторная проверка: `scripts/verify-community-live.cjs` и `scripts/verify-web-push-live.cjs`; требуется `SUPABASE_BIN` с путём к авторизованному нативному CLI. Проверки создают временные аккаунты и удаляют только собственные данные. Локальный стенд: `npm run test:community-ui`.
