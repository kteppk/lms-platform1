# 0.7.5 — состояние прочитанных уведомлений

Исправлена разблокировка постоянной кнопки «Прочитать эту страницу» после завершения её обработчика. Раньше общий обработчик безусловно включал кнопку повторно, переопределяя состояние, рассчитанное по обновлённому списку. На медленном соединении она оставалась доступной до следующего ответа сервера. Теперь после действия доступность определяется наличием непрочитанных карточек в том же окне или на той же странице; при ошибке прочтения можно повторить действие.

Браузерная проверка контролирует недоступность кнопки сразу после прочтения и после повторного открытия окна. Компактные меню и остальные изменения 0.7.4 сохранены. Статические файлы и офлайн-кэш используют новую версию, чтобы устройства не сохраняли промежуточный код.
